§ 08 / FAQ

Common questions, plainly answered.

01

Do I need a domain?

Yes — or we can buy one for you (cost + a small admin fee). We'll point it for you either way.

02

Can you write my content?

Yes. Tell us your services, your area, and your phone number — we'll write minimal, punchy copy that doesn't sound like AI.

03

What if I don't like the first version?

You get three rounds of changes included. After that, additional changes are $50 each. In practice, almost no one needs all three.

04

Why San Francisco / the Bay Area only?

Because we know the cities, the neighbourhoods, the licensing bodies, and the way Bay Area customers actually search for a contractor. The site reads like it was written by a local — because it was.

05

Is this just a template you change the colours on?

No. Every site is hand-coded HTML & CSS. No WordPress, no Wix, no Squarespace, no AI-generated boilerplate. You'll own the actual source code and can host it anywhere.
